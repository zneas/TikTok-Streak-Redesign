# TikTok-Streak-Redesign

MVP for the redesign of TikTok's DM Streak feature. Team Astrophage, ITE 14 (UX Concepts and Design), Saint Louis University.

The redesign moves streaks away from "don't lose the number" toward real interaction with a friend: it shows which videos you've watched or replied to, makes the streak number quieter and optional, adds a shared streak pet, and lets you set flexible streak rules.

## Repo contents
- `CLAUDE.md`: project brief, stack, design decisions, and the MVP screen flow.
- `design/`: design tokens (`tokens.json` is the source; `tokens.css` is generated with `node design/build-tokens.mjs`).
- `docs/screens/`: PNG exports of the prototype screens.
- `docs/tester-guide.md`: usability test tasks.
- `docs/*.pdf`: research plan, design thinking, evaluation template.
